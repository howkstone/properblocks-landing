Deleting documents

Only the block's directors can delete documents from the portal. When a document is deleted, it is removed from the portal immediately and stops appearing for any user. After 30 days the file is permanently deleted from our storage and cannot be recovered.

The audit log entry recording the deletion is kept indefinitely and is not affected by the 30-day window. This is so we can prove what was removed, by whom, and when, if a dispute arises.
